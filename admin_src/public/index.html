Servers

Each server here runs the audio engine. New listeners go to the one with the fewest listeners, in proportion to its weight. The domain listeners use never changes.

Server management is switched off (HAPROXY_ADMIN is not set), so changes here are saved but not applied.

Updates

Automatic updates

Once a day at this time the server checks for a newer version and installs it. The database is backed up first. Listeners are disconnected for a few seconds while services restart, so pick your quietest hour. Slave nodes follow the master's version by themselves.
